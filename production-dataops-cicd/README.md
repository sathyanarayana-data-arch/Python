# Project 3: Production DataOps, CI/CD, & Data Observability

## 📌 Overview
Enterprise reliability platform incorporating automated testing, Infrastructure as Code, and production data observability.

## 🏗️ Architecture Flow
`GitHub Code Commit` ➔ `GitHub Actions CI/CD Pipeline` ➔ `Automated Linting, Terraform Provisioning & dbt Testing` ➔ `Production Deployment`

## 🛠️ Tech Stack
* **CI/CD Automation:** GitHub Actions
* **Infrastructure as Code:** Terraform
* **Transformations:** dbt-core
* **Data Observability:** Great Expectations / Elementary

## ⚙️ Key Skills Demonstrated
* **Infrastructure as Code (IaC):** Programmatic provisioning of cloud storage buckets and analytical database resources via Terraform.
* **CI/CD Automation:** Enforcing code quality, SQL linting, and automated test execution on every pull request prior to deployment.
* **Data Observability:** Automated monitoring for data freshness, volume anomalies, and schema drift.
